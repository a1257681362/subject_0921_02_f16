## 冒烟记录（真实 HTTP，证据摘录）

1. **打码级交接班登记**（管家 steward01）
   - 提交 content=`有事请加微信沟通`（种子词「加微信」=打码级）
   - 返回 200，`content="有事请***沟通"`，`status=DRAFT`，记录正常落库。

2. **分隔符插空拦截 + 位置定位**
   - 提交 content=`日常代-开 发·票广告`
   - 返回 `success=false`：`字段[content]命中[代开发票(位置2-9)]`；记录未落库。
   - 命中痕迹 `rawExcerpt="日常代-开 发·票广告"`，`startIndex=2,endIndex=9`（区间长 7，覆盖 4 个汉字之间的 3 个插空字符 `-`/空格/`·`），`actionTaken=BLOCK`，`username=steward01`。

3. **变形词**：租约备注 `赌-博网站` → 拦截 `命中[赌博(位置0-3)]`。
   自动化另覆盖：全角字母 `ＣＡＳＩＮＯ→casino`、形近 `c4sh→cash`、零宽字符插空 `加[ZWSP]微信`。

4. **命中痕迹**：`GET /api/apartment/sensitive/audits?module=HANDOVER`（管理员）
   返回账号、请求号（REQ-SMOKE-*）、模块、业务定位（小区/楼/日期）、字段、词条、字位、原文片段、打码结果。

5. **词典后台维护即时生效**
   - 主管 POST `/words` → **403**（无 manage 权）；管家 GET `/words` → **403**。
   - 管理员新增「群租」(BLOCK) → 管家随后提交 `房屋群租信息` 即被拦截（无需重启）。
   - 管理员停用该词 → 同样内容提交 200 放行。
   - `GET /word-logs`：`CREATE admin 群租`（停用动作同样有一条）。

6. **接班状态机**
   - 交班人本人确认 → `交班人与接班人不能为同一人`；
   - 主管确认 → `status=CONFIRMED, takeOverBy=supervisor01`；
   - 重复确认 → `该交接班记录已确认，不能重复确认`。

7. **旧库升级**：对已存在的 apt-3 文件库直接启动成功，4 张新表与 `t_lease.remark` 自动建成，
   种子 8 词写入；冒烟后已清理测试数据，库内恢复为仅种子词。

## 关键设计核对

- 拦截痕迹以 `REQUIRES_NEW` 独立事务提交：SensitiveFlowTest 第 2 个用例验证业务记录数不变而痕迹仍在。
- 种子词不写死自增 id（修复 H2 IDENTITY 序列不随 MERGE 推进导致新增撞主键的问题），
  且仅在词库表为空时播种，后台维护结果重启不丢。
- 数据范围：交接班 SELF 可见本人交班/接班记录，SCOPE 按授权小区，ALL 全部；每次检索落 `t_data_scope_audit`。
