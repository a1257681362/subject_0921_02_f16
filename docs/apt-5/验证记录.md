## 2. 真实启动冒烟（独立文件库 + 临时端口 8099）

以 `target/classes` + 本地依赖启动（离线环境无法下载打包插件，等价生产 classpath），
真实账号登录后走完整演示链路：

1. supervisor01 登记台账 `PROP-DEMO-001`（示例小区）→ 200。
2. steward01 `POST /api/apartment/sign-archive/tasks`（合同 HT-DEMO-2026-0001）
   → 立即返回 `PENDING / progress=0 / totalSteps=20 / taskNo=TASK-...-5bf2b16c`。
3. 前端口径轮询（500ms）实测进度：

   ```
   poll#1  PENDING   0%  排队中
   poll#2  RUNNING  35%  生成签署文书
   poll#3  PENDING  55%  等待租客签署      ← 等租客签署，任务延后重领不空转
   poll#4..15 PENDING 55% 等待租客签署     （sign-wait-ms=800 + 轮询间隔）
   poll#16 SUCCESS 100%  已完成
   ```

4. 最终详情：`status=SUCCESS, progress=100, currentStep=20`，
   result 含 leaseId/archiveId/platformFlowNo/platformDocToken/signUrl/signedFileName/signedAt；
   `retainUntil=2026-10-07`（终态 2026-09-23 +14 天，保留期正确）。
5. `GET /api/esign-demo/flows` 平台侧可见该流程 `status=FINISHED, signer=李雷`；
   `/api/esign-demo/console` 演示页 HTML 正常返回。
6. 租约库内 ACTIVE 且回写 sign_archive_id；归档行 FINISHED、已签章文件为平台凭证文本。
