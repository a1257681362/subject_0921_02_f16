# apt-5 签约归档后台任务化 + 电子签章平台对接 上线说明

- 模块：`com.evops.apartment.task`（新增）、`com.evops.apartment.esign`（新增）、`schema.sql`（增量）
- 上线日期：2026-09-23

## 1. 本次交付内容

运营周会改造项：**签约归档这种慢操作挪到后台**，接口不再阻塞等待电子签章平台。

1. **任务表登记**：发起接口只做范围校验、房源核验、敏感词处置与任务登记，立即返回任务号；
   后台调度器认领 `PENDING` 任务执行（`t_async_task`，DB 条件更新 CAS 认领，多线程/多实例不重复执行）。
2. **进度按 5% 一步推进**：签约归档拆为 **20 个一致步骤**，每完成一步进度 +5：

   | 步 | 环节 | 步 | 环节 |
   |---|---|---|---|
   | 1 | 平台连通自检 | 11 | 归档行登记(SIGNING) |
   | 2 | 核验房源台账 | 12 | 等待租客签署(轮询) |
   | 3 | 签约要素复核 | 13 | 签署完成确认 |
   | 4 | 组装合同文书 | 14 | 平台盖章 + 复核 |
   | 5 | 提交用印申请 | 15 | 归档回写租约 |
   | 6 | 租约建档落库 | 16 | 回传已签署文件 |
   | 7 | 租约回读复核 | 17 | 文件完整性校验 |
   | 8 | 生成签署文书 | 18 | 归档置 FINISHED |
   | 9 | 发起租客签署 | 19 | 最终一致性复核 |
   | 10 | 签署链接送达确认 | 20 | 收尾产出汇总 |

   步骤边界即**提交边界 / 取消边界 / 断点边界**：步骤库内写入各自独立短事务，
   进度行随独立事务提交，平台调用不裹长事务、不占数据库连接。
3. **前端轮询可查**：`GET /api/apartment/sign-archive/tasks/{taskNo}` 返回
   status/progress/currentStep/stepName/failStep/failReason/cancelRequested/cancelable/retryable/result。
4. **支持取消，停在下个一致步骤**：执行器在每个步骤执行前重新读取取消标记——
   当前步骤完整提交后才停，进度恒为 5 的整数倍，落 `CANCELLED`；
   排队中（PENDING，含等签署延后）取消立即停在当前断点。取消后可断点重跑。
   取消与「调度认领（PENDING→RUNNING）」「等签署退回（RUNNING→PENDING）」并发翻转时，
   由两处条件更新夹击闭合：等待退回仅在未申请取消时才降回 PENDING，否则就地落 CANCELLED；
   取消接口的条件更新落空会按最新状态有界收敛——任一时序下取消都不会被吞掉而后台续跑。
5. **失败可断点重跑**：步骤异常落 `FAILED` + `fail_step`/`fail_reason`，
   `POST .../{taskNo}/retry` 从 `current_step+1` 续跑。三重幂等保证不产生重复数据：
   - 已完成步骤由进度行确认，不重跑；
   - 库内写入先查后写（合同号唯一、归档行合同号唯一）；
   - 平台所有写操作以固定业务幂等号 `EVOPS-{合同号}` 去重。
   实例宕机：启动时把遗留 `RUNNING` 回收为 `PENDING` 续跑。
6. **任务记录保留 14 天**：终态（SUCCESS/FAILED/CANCELLED）写 `retain_until = 终态时间+14天`，
   每日 01:17 定时清理过期记录（可配）。
7. **电子签章平台对接**：独立一层 `ESignClient`。
   - 默认 `provider=mock`：进程内模拟平台，**零外部依赖，下周演示开箱即用**；
     演示控制台 `/api/esign-demo/console`（查看平台签署流程、手动点“租客完成签署”掌控节奏；
     不操作时默认约 1.5 秒自动签署）。
   - `provider=http`：真实网关，HMAC-SHA256 签名（METHOD\PATH\ts\nonce\tbodyMd5）、
     连接/读取超时、bizNo 业务幂等；**对接只改配置与本类内字段映射，任务步骤与业务接口不动**。
     客户端不自动重试，超时即失败断点，由任务侧重跑（幂等号兜底，绝不重复用印）。

## 2. 新增接口（均需登录，`/api/**`）

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | `/api/apartment/sign-archive/tasks` | `apartment:sign:submit` | 发起签约归档，秒回任务号 |
| GET | `/api/apartment/sign-archive/tasks` | `apartment:sign:view` | 任务列表（status/contractNo，按数据范围过滤） |
| GET | `/api/apartment/sign-archive/tasks/{taskNo}` | `apartment:sign:view` | 轮询进度详情 |
| POST | `/api/apartment/sign-archive/tasks/{taskNo}/cancel` | `apartment:sign:cancel` | 取消（下一步边界停） |
| POST | `/api/apartment/sign-archive/tasks/{taskNo}/retry` | `apartment:sign:retry` | 失败/取消任务断点重跑 |
| GET | `/api/esign-demo/console` | （mock 演示页，免权限） | 电子签章平台演示控制台 HTML |
| GET/POST | `/api/esign-demo/flows[/{flowNo}/complete]` | （mock 演示用） | 平台流程查询 / 模拟租客签署 |

数据范围沿用 apt-3：SELF 仅本人发起的任务，SCOPE 限授权片区房源的任务，ALL 全部；
逐请求落放行审计。权限点 20–24（1 菜单 + 4 按钮）授予管家/片区管家/主管/管理员。

发起请求体与租约建档同口径（contractNo/propertyCode/租客信息/租期/租金押金/remark/requestNo/operator），
remark 同步过 DFA 敏感词（拦截级发起失败、不建任务；打码级以处置后文本入任务）。

## 3. 新增表 / 变更

- `t_async_task`：后台任务登记（状态、进度、步骤、断点 checkpoint CLOB、payload CLOB、
  取消标记、失败步骤/原因、锁、next_run_at、retain_until）。
- `t_lease_sign_archive`：签约归档凭证（合同号唯一、平台流水/文书标识、状态 SIGNING→SIGNED→SEALED→FINISHED、
  已签署文件 CLOB、签署时间）。
- `t_lease` 增加 `sign_archive_id`（幂等 `ALTER TABLE ADD COLUMN IF NOT EXISTS`，旧库自动升级）。
- 权限点 20–24 与四种角色授权（MERGE 幂等）。

全部为增量变更，`CREATE TABLE IF NOT EXISTS` + 幂等补列，旧文件库启动自动升级。

## 4. 配置

```yaml
evops:
  esign:
    provider: mock              # mock / http
    base-url: http://esign-gateway.internal
    access-key: ""
    access-secret: ""
    connect-timeout-ms: 3000
    read-timeout-ms: 10000
    mock:
      step-delay-ms: 200        # 演示时每步耗时（进度可见节奏）
      sign-wait-ms: 1500        # 模拟租客自动签署等待
  task:
    enabled: true               # 后台执行总开关（false 只登记不执行，应急用）
    batch-size: 2               # 本机并发任务数
    dispatch-interval-ms: 2000  # 派发扫描间隔
    sign-poll-interval-ms: 5000 # 等租客签署时延后重领间隔
    retain-days: 14             # 终态记录保留天数
    cleanup-cron: "0 17 1 * * ?"
```

## 5. 部署步骤

1. 备份 `data/evops.mv.db` 与在用 jar。
2. `mvn -DskipTests package`，替换 jar 后启动；schema 自动增量升级。
3. 本周（mock）：打开 `http://host:8080/api/esign-demo/console` 可配合演示。
4. 下周对接真实平台：拿到地址/密钥后设置 `evops.esign.provider=http` 及 `base-url/access-key/access-secret`；
   若平台报文口径与约定不同，仅调整 `HttpESignPlatformClient` 内 URL/字段映射。
5. 验证：按 `docs/apt-5/验证记录.md` 冒烟。

## 6. 回滚

- 任务功能为纯增量：回滚 jar 后既有租约/台账/交接班数据不受影响，新表/新列保留无副作用。
- 应急不回滚时：`evops.task.enabled=false` 暂停后台执行（任务仍可登记与查询，不再推进）；
  电子签章侧 `evops.esign.provider=mock` 可切回模拟。
- 同步建档旧接口 `POST /api/apartment/leases` 保持不变，后台化出问题时业务仍可走旧链路兜底。
